# Koncept DETECO (sk-deteco)
Tri koncepty:
1. **Spis** – web ako zložka prípadu: záložky, razítko DÔVERNÉ, postup „Kontaktujte nás → Záver“ ako chronológia spisu.
2. **Tienidlo** – tmavá noirová stránka s kužeľom svetla nad fotkou (príliš „filmové“, hrozí tmavý luxus).
3. **Šifra** – redakčný web s redigovaným (začierneným) textom, ktorý sa odhaľuje (gimmick, pri citlivých službách pôsobí hravo).

Výber: **Spis**. Obor je o diskrétnosti a dôkaze; zložka prípadu je vecná, nie lacná tajomnosť. Brand: logo biele na tmavom (tmavá hlavička), modrá #0170b9 z ich webu, zlatá #e8bd6d len ako drobný akcent razítka.
Sekcie: hlavička/úvod (fotka detektíva + „Spis: váš prípad“) / ponuka služieb ako záložky-karty / o kancelárii a zákonný rámec / postup ako chronológia spisu (6 krokov z ich webu) / napísali o nás (3 články z ich webu) / kontakt s formulárom „Diskrétne odoslať“.
Signature: razítko DÔVERNÉ pri formulári a postup ako zvislá časová os spisu. Pohyb: len jemný reveal.
Písma: Schibsted Grotesk (400/700) + IBM Plex Mono pre štítky spisu; háčky testované renderom (QA).
Zakázané vzory: žiadne (bez marquee, zrna, counterov – 0 % ukazovatele ich webu vynechané; nadtitulky nie sú číslované).
Porovnanie: predchádzajúce weby Young Serif / Bodoni Moda → iný display font. Skladba iná než vzorkovník (Vejár) a tanečné štúdio.
Pravdivosť: fakty len z deteco.sk; „od 2010“ z loga; „viac ako 10-ročná prax“ z ich článku; žiadne štatistiky.
